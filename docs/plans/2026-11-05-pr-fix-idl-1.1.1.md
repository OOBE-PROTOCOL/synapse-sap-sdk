## What

Reconciles the release gates to the IDL the SDK actually ships, then removes
two structural sources of diff noise.

## Why

- `94f392c` / `5b0f1c6` aligned the embedded IDL to **v1.1.1** (80 ix / 25 accounts /
  61 events, byte-identical to the on-chain program) but left the smoke test and the
  release gate pinned to **1.0.3** → CI red on main, `verify:release` failing.
- `REGISTRATION_FEE_LAMPORTS` still said **0.1 SOL** — the on-chain program v1.1.1
  registration fee is **40_000_000 lamports (0.04 SOL)**
  (`syanpse-sap` repo, `programs/synapse-agent-sap/src/constants.rs:10`).
- `node_modules/` was **tracked in git** → every install produced thousands of
  spurious diffs (a single `npm ci` churned 12.9 MB of diff).
- `yarn.lock` was tracked while `sdk-ci.yml` uses `npm ci` from
  `package-lock.json`; npm@11 additionally **mutates yarn.lock on every install**
  (dedupe churn) — keeping both lockfiles meant recurring unexplained changes.

## Changes (2 commits)

### `0da7489` — fix: reconcile release metadata to SDK IDL 1.1.1
| File | Change |
|---|---|
| `src/__tests__/smoke.test.ts` | expects IDL metadata `1.1.1` (test renamed accordingly) |
| `scripts/verify-release.mjs` | `expectedProgramVersion = "1.1.1"` (+ Prettier reformat of the whole file — pre-existing style debt, no logic change) |
| `src/constants/treasury.ts` | `REGISTRATION_FEE_LAMPORTS 100_000_000 → 40_000_000` + doc comments (header fee list and constant) |
| `CHANGELOG.md` | `[Unreleased]` section documenting the reconciliation |

### `e2e88d6` — chore: untrack node_modules / drop yarn.lock
- `.gitignore` + `git rm -r --cached node_modules` (6861 tracked files removed from the index, nothing on disk)
- `yarn.lock` deleted; `package-lock.json` is the single lockfile (`sdk-ci.yml` = `npm ci`)
